Retrieval Chatbot

Overview

This project implements a simple retrieval-based chatbot using Python and Scikit-Learn.

Features

- Reads knowledge from a text file
- Retrieves the most relevant answer
- Uses TF-IDF Vectorization
- Uses Cosine Similarity

Technologies

- Python
- Scikit-Learn
